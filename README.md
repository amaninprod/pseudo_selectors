## 📖 Overview

**Pseudo Selectors** is a CSS pseudo-classes and pseudo-elements practice project. It demonstrates how to style elements based on their state and position using CSS pseudo-selectors.

> 🎯 **Purpose:** CSS pseudo-selector learning and practice

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎭 **Pseudo-Classes** | :hover, :focus, :active, :nth-child, etc. |
| 🎨 **Pseudo-Elements** | ::before, ::after, ::first-letter, etc. |
| 📱 **Responsive** | Works on all devices |
| ⚡ **No Dependencies** | Pure HTML/CSS |
